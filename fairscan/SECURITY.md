# Segurança

- Baixe o `FairScan.exe` **somente** da página de Releases deste repositório e confira o SHA256 publicado em
  `SHA256SUMS.txt`. O executável é gerado automaticamente pelo GitHub Actions a partir do código público.
- O FairScan é somente leitura e não precisa de internet (exceto o download opcional da allowlist pública do Roblox).
  Desconfie de qualquer "versão" que peça senha, login do Roblox ou desative o antivírus.
- Encontrou uma vulnerabilidade, ou um jeito de o scanner coletar mais dados do que o documentado? Abra uma issue
  marcada como `segurança` ou entre em contato com os mantenedores em particular.
